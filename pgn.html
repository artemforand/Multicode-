PGN Graphics & Language

Полное справочное руководство по синтаксису, операторам, графическим объектам и системным API HorizonOS.

Критическое правило: Пробелы в коде

ВСЕГДА ИСПОЛЬЗУЙТЕ ПРОБЕЛЫ!
В PGN GRAPHICS парсер требует обязательного разделения пробелами для всех токенов, операторов, переменных и кавычек. Слитно писать нельзя!

❌ Неправильно (Ошибка парсера)

name=123
n $= "text"
val = 1+2

✅ Правильно (Работает)

name = 123
n $= " text "
val = 1 + 2

Переменные и Область видимости

В PGN GRAPHICS переменные делятся на глобальные и локальные. Регистр символов учитывается.

Глобальные

Глобальный контекст

Доступны во всех файлах и во всех структурах проекта.

Создание
name = 123

Получение: внутри математических операций — просто name, вне операций — с префиксом _name.

Локальные

Локальный контекст

Можно создавать где угодно! Работают в текущем файле или внутри структур (if, for, timer).

Создание
local name = 123

Получение: всегда через префикс *name (и внутри, и вне выражений).

Множественная инициализация
Можно создавать несколько переменных в одну строку через запятую: name = 10 , n = 2

Обратите внимание: ключевое слово local работает только для первой переменной после него (например, в local name = 10 , n = 2 переменная n станет глобальной).

Присваивание, Проверка на nil и Консоль

Особые операторы
n += 10        -- Прибавляет 10 к текущему значению (работает с любым оператором)
name ??= 100   -- Если переменная НЕ СОЗДАНА (или равна nil / 0) — создать и записать значение
n $= " тут что угодно " -- Вывод строки/значения в консоль

Работа со строками

PGN поддерживает автоматическое склеивание строк и переменных, а также специальные символы конкатенации.

Конкатенация
-- Операторы конкатенации:
..             -- Склеить со следующим словом
/n             -- Перевести на новую строку и склеить следующее слово

-- Строка перед которой НЕ нужно писать .. склеивается сама:
Name = .. text
N = name name .. text " строчка "

-- Итог N: "texttexttextстрочка"

Особенности и Лайфхаки

Временные решения интерпретатора
  • Запись нуля как числа: При n = 0 ноль запишется как строка. Чтобы записать численный 0, используйте: n = 0 + 0.
  • Отрицательные числа: Чтобы сделать число отрицательным, умножайте его: n = 10 * -1.

Динамический подставной вызов

Значения с префиксами _ и * заменяются на содержимое переменных в командах:

Динамический вызов
д = .. new.rect
_д name 0 0 100 100 12 -- Вызовет new.rect с аргументами

-- Ограничение: не работает напрямую в присваивании переменных!
д = .. name            -- ❌ Ошибка!
_д = .. text           -- ❌ Ошибка!

Цикл for

Конструкция цикла
for name от до шаг запись_в_переменную {
    -- Исполняемый код
}forend_name

-- Пример использования:
for n 1 100 1 i {
    local n = *i * 100
}forend_n

Условие if

Операторы проверки: =, ==, ≈, ≠, >, <, ≥, ≤. Поддерживается передача локальной переменной в контекст блока.

Логическое ветвление
if name значение1 =/==/≈/≠/>/-- Исполняемый код
}ifend_name

-- Пример:
if n 1 = 2 ( n ) {
    -- Выполнится если 1 равно 2
}ifend_n

Таймер timer

Интервальный таймер
timer name каждые(сек) сколько_повторов ( передать_локальную_переменную ) {
    -- Код цикла таймера
}timerend_name

-- Пример:
timer n 0 60 ( i ) {
    -- Код
}timerend_n

Графические объекты

Прямоугольник new.sRect

Создает векторный прямоугольник с раздельной настройкой скругления каждого из 4 углов.

new.sRect
new.sRect name x y шир выс скруг1 скруг2 скруг3 скруг4 количество_точек поворот

-- Пример (рекомендуемое качество точек 100-200):
new.sRect name 0 0 100 100 15 15 0 0 100 0

Параметры объектов

Цвет и Непрозрачность
-- Установить RGB цвет и непрозрачность (0-100)
object.color.rgb name r g b [непрозрачность]
object.color.rgb name 255 255 255
object.color.rgb name 255 255 255 100

-- Установить только непрозрачность (0-100)
object.opacity name непрозрачность
object.opacity name 100

Текстовые элементы

Создание и управление текстом
-- Обычный текст:
new.text name text x y размер шрифт непрозрачность(0-100)
new.text name myText 0 0 36 medium 100

-- Текст с шириной, высотой и выравниванием (left / center / right):
new.TextWH name text x y размер шрифт непрозрачность ширина высота выравнивание
new.TextWH n MyText 0 0 36 medium 100 1000 100 center

-- Динамическое изменение текста:
text.change имя новый_текст

-- Цвет и Прозрачность текста:
text.color.rgb name r g b [непрозрачность]
text.opacity name непрозрачность(0-100)
